# 扇贝生词助手(Vocab Helper)

在扇贝背单词时,**你只要点"不认识",单词就会自动进队列**——攒几个后一键交给 AI,得到词源故事级的深度讲解。全程不用截图、不用复制、不用打字提问。

> 核心场景:背 GRE 词表时软件释义太简略,想要"为什么这个词是这个意思"(词根逻辑)+ 怎么记牢。本工具把"逐个截图问 AI"的繁琐流程自动化了。

## 功能

- **自动收集生词**:监控屏幕上的扇贝单词页,识别到你点了"不认识"(黄条出现)→ 自动把该词加入待解释队列
- **重复词追踪**:背过又忘的词会被标记「已出现过 N 次」,默认不重复解释,可选择「再解释」
- **一键批量讲解**:攒 3~5 个词,点一下,AI 流式输出【词根故事】【家族】【例句】——讲透"字面义→引申义"的演变
- **追问对话**:还能补充你自己的联想(如"这词我总觉得像法语"),AI 会针对性"破案"
- **完整记录**:每天的对话、生词、重复次数都存为 Markdown,随时翻阅
- **对话即配置**:讲解风格、输出结构都在系统提示词里,可自由修改

## 快速开始

### 方式一:直接用 exe(推荐给非开发者)

1. 到 **[Releases](https://github.com/weileyao2005/Vocab_helper/releases/latest)** 下载 `扇贝生词助手.exe`,双击运行
2. 首次运行:拖框选中扇贝的**黄色提示条 + 单词**区域(框大一点没关系)
3. 弹出设置窗:填入你自己的 **DeepSeek API Key**(在 <https://platform.deepseek.com> 申请)
4. 之后每次双击即用

> 若 Windows 提示"未知发布者":点「更多信息」→「仍要运行」。
> 你的所有数据(配置、记录、API Key)都保存在你自己电脑的 `%APPDATA%\扇贝生词助手\`,exe 文件本身不含任何数据,可放心转发。

### 方式二:从源码运行

```bash
pip install -r requirements.txt
python vocab_helper.py
```

环境要求:Windows 10/11(依赖系统自带的 OCR 组件,中文语言包通常已内置)、Python 3.10+。

## 配置

| 配置项 | 说明 |
|---|---|
| API Key | DeepSeek 或任意 Anthropic 兼容端点的 key,在程序内「设置」里填写 |
| 接口地址 | 默认 `https://api.deepseek.com/anthropic`,可换成其他兼容端点 |
| 模型名 | 默认 `deepseek-flash` |

也可手动编辑程序目录下的 `api.json`:

```json
{
  "api_key": "sk-...",
  "base_url": "https://api.deepseek.com/anthropic",
  "model": "deepseek-flash"
}
```

## 技术说明:为什么用 Windows 系统 OCR

这个工具的核心是"每 0.15 秒看一眼屏幕固定区域,判断有没有出现'不认识'的黄条、当前单词是什么"。选型先后试过三代方案,实测对比:

| 方案 | 单次识别 | 轮询周期 | 准确率(63 张真实截图回归) | 问题 |
|---|---|---|---|---|
| tesseract | 0.4s | 0.4s | 需大量补丁逻辑,依赖精确框选 | 词大词小就翻车 |
| RapidOCR (PaddleOCR/ONNX) | 0.55~0.9s | 0.8s | 62/63 | 慢;多核推理满载,风扇噪音明显 |
| **Windows 系统 OCR(winrt)** | **5~90ms** | **0.15s** | **58/63 + 3 个近似**(AI 纠错兜底) | 无明显短板 |

结论:**Windows 自带的 `Windows.Media.Ocr` 是屏幕文字场景的最优解**——模型作为系统服务常驻,调用是毫秒级、CPU 占用近乎为零;它的训练数据覆盖海量系统 UI 截图,对"屏幕渲染的文字"天然匹配。(它的名字在 pip 生态里搜不到,是本项目最容易忽略的发现。)

词提取的逻辑:OCR 返回每个词的边界框,**字号最大的英文词 = 当前正在背的单词**;黄条用关键词 + 字符覆盖率模糊匹配,容忍 OCR 零星错字(如"这个"→"汶个")。

## 数据与隐私

- API Key 只存本机(`api.json`),**代码与打包产物中不含任何 Key**
- 学习记录只存本机;exe 文件无状态,转发不会带出任何使用者的数据
- 本工具仅通过屏幕像素识别页面,不访问、不修改扇贝的任何接口

## 许可

个人学习使用。扇贝是扇贝网的产品,本工具与扇贝官方无关。
